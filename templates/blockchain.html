Basic Application-Level Blockchain Prototype

This is a basic application-level blockchain prototype built with Python and hashlib.sha256. Each block is cryptographically linked to the previous block via SHA-256 hashes and Proof-of-Work difficulty target (00...). It demonstrates immutable supply chain provenance for educational and verification purposes, rather than operating as an open public blockchain network.
